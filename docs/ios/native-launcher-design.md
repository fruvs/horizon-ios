# Native launcher design

The SwiftUI launcher uses a custom branded sidebar on iPad and a floating navigation island on compact screens. Play contains only the game cover and any required game-file setup. Worlds and Servers are deliberately absent from launcher navigation and home shortcuts; players use Minecraft’s own menus after Play. The account sheet opens from a 48-point circular control in the custom page header; signed-in Minecraft names are read-only, while offline names remain editable.

Use semantic UIKit colors and system type so light/dark appearance and Dynamic Type follow the device. Keep Liquid Glass on navigation and controls, using SwiftUI's native glass button styles on iOS 26 and later; older supported systems use bordered buttons and system materials. Content lists retain solid grouped surfaces for legibility. Teal is the primary accent, with orange and indigo reserved for category markers; there is no dominant purple surface or bundled custom font.

Scenery comes from the player's imported title panorama or their world's thumbnail. Neither game assets nor screenshots are bundled with the launcher. Before imports are available, a simple original landscape fallback keeps the layout usable. Avoid restoring the old promotional splash animation, duplicated account panels or device-status chips on Play.

The launcher branch starts from the device-tested build 16 source, before upstream removed the launcher. Native world creation now sends typed JSON through `world-create`, preserving names/seeds with spaces and mapping mode, difficulty, cheats, world type, structures and bonus chest to the existing `WorldOptions`. Hardcore locks Hard difficulty and disables cheats/bonus chest at both UI and engine boundaries. The separate direct-title experiment remains intact. No PR or push is part of this design iteration.

The official `docs/media/brand/mark-dark.svg` is included unchanged as a template image, displayed monochrome. The older world-management views and helper types remain in source for their shared scenery/data helpers, but the launcher exposes no world library, server browser, recent-world carousel or creation entry point. Saved worlds and the game’s own menus are untouched. The launcher no longer fetches those lists at startup. Server descriptions consume legacy Minecraft color/style/RGB codes, with readable accessibility text and semantic reset styling. Unknown section-sign sequences remain literal text.

The compact navigation island has 20-point side gutters and an 22-point clearance measured directly from the screen’s bottom edge (rather than adding padding above the home safe area). Its three controls (Play, Packs, Settings) have at least 44-point touch targets. The dock is at most 280 points wide. Compact content reserves 92 points of scroll clearance so the last controls can move above the island. One capsule receives the native Liquid Glass effect on iOS 26+, with a regular-material capsule on iOS 18. Reduce Transparency uses a solid surface. Selection animation is scoped to the dock so navigating does not crossfade complete page stacks. Settings uses expandable configuration panels and keeps native sliders and toggles for reliable input.
